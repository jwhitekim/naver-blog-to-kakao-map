# Placepick 디자인 시스템

이미 확정된 디자인 시스템이 있다. 전체 리서치·자체검토 과정은 `docs/design-spec.md`에 있고, 여기는 지켜야 할 값과 규칙만 요약한다.

## 팔레트 (바꾸지 않는다)

| 변수 | 값 | 용도 |
|---|---|---|
| `--paper` | `#E8EAE0` | 배경 전체(세이지그레이, 장부 종이 톤) |
| `--ink` | `#1F2A24` | 본문 텍스트 |
| `--muted` | `#757F70` | 보조 텍스트 |
| `--line` | `#C7CBB8` | 헤어라인 |
| `--brand` | `#A23B2E` | 앱의 유일한 강조색(오크스블러드). 새 강조색을 추가하지 말고 이걸 쓴다 |
| `--kakao` `#FFCD00` / `--naver` `#03C75A` | 실제 서비스 브랜드색 — 카카오맵/네이버 링크 구분용으로만, 장식으로 쓰지 않는다 |

크림 배경(`#F1ECDF` 계열)은 의도적으로 피한 색이다 — AI가 흔히 고르는 기본값이라는 피드백으로 세이지그레이로 바꿨다. 되돌리지 않는다.

## 타이포그래피

**Pretendard 하나만 쓴다.** 세리프나 모노스페이스를 새로 추가하지 않는다. 위계는 `font-weight`(본문 400, 표제 700, 데이터/강조 700~800)와 자간(`-.01~-.02em`)으로만 표현한다.

## 컴포지션 규칙

- **박스를 쌓지 않는다.** 흰 배경 + `border-radius` 큰 카드 + `box-shadow`로 섹션을 감싸지 않는다. 배경은 한 장으로 이어지고, 섹션 구분은 `.rule`(`border-top: 1px solid var(--line)`) 헤어라인만 쓴다.
- **장식용 pill 라벨을 만들지 않는다.** "STEP 01" 같은 콘텐츠와 무관한 배지 대신, 실제 정보를 담은 eyebrow 텍스트(`.section-eyebrow`)만 쓴다.
- **시그니처는 도장 하나뿐이다.** 이중 원 배지(`.row-stamp`, `.hero-stamp`)가 "언급 횟수"를 표현하는 이 앱의 유일한 장식 요소다. 별점이나 다른 배지 스타일을 새로 만들지 않는다.

## 필수 규칙

`body`에 `word-break: keep-all`이 전역으로 걸려 있다 — 한글이 단어 중간에서 줄바꿈되는 걸 막기 위한 것으로, 개별 요소에서 덮어쓰지 않는다.

## 검증

`npm run build` 통과 확인은 최소 조건이다. 가능하면 실제 브라우저로 화면을 띄워 확인한다(desktop + mobile 폭). 이 환경의 리사이즈 도구가 불안정할 수 있으니, 확인 못 했으면 못 했다고 말한다.
