# Security Policy

Placepick is a personal project maintained by one person, not a company with
a dedicated security team — please keep that in mind when reporting and
waiting for a response.

## Reporting a vulnerability

**Please don't open a public GitHub issue for a security vulnerability.**
Instead, report it privately using one of these:

- [GitHub Security Advisories](https://github.com/jwhitekim/naver-blog-to-kakao-map/security/advisories/new) (preferred)
- Email: kimjunhee2483@gmail.com

Please include what you found, how to reproduce it, and its potential impact.
I'll acknowledge reports within a few days and let you know once a fix is out.

## Scope

- The app code in this repository (backend and frontend).
- The [live demo](https://plick.2joon.com/) — note it runs on the
  maintainer's own Gemini/Kakao/Naver API keys and quota, so please don't
  use it to test rate-limiting or resource-exhaustion issues against those
  third-party services.

Vulnerabilities in third-party dependencies should generally be reported
upstream, but feel free to flag them here too if you're not sure.
