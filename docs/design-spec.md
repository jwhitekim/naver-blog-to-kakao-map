# Placepick 디자인 명세서

리서치 → 명세 → 자체 검토 → 적용 순서로 정리합니다. 코드 적용 전 검토용 문서입니다.

## 1. 문제 정의

지금 화면(인스타그램 그라데이션 팔레트, 흰 배경 + 둥근 모서리 + 그림자 박스를
세로로 쌓은 구조)은 "AI가 만든 티가 난다"는 피드백을 받았다. 원인을 색·폰트가
아니라 **구조**에서 찾았다:

- 모든 섹션이 독립된 흰 카드(패널)로 떠 있다 — `search-panel`, `loading-card`,
  `results` 전부 같은 패턴(배경 흰색 + border-radius + box-shadow).
- 콘텐츠와 무관한 장식용 pill 라벨("START PICKING", "STEP 02")이 헤딩 위에
  반복된다.
- "작동 방식" 섹션이 아이콘+숫자+제목+설명 박스 3개로, 전형적인 부트스트랩
  feature-grid다.

이건 개별 요소(카드 모서리 둥글기, 그림자 세기)의 문제가 아니라 **"박스를
쌓는" 조립식 구조 자체**의 문제다. 한눈에 훑었을 때(편의점에 들어가서 진열
상태를 직관적으로 느끼는 것처럼) 전체가 하나의 완결된 화면이 아니라 컴포넌트
라이브러리에서 부품을 가져와 쌓은 것처럼 읽힌다.

## 2. 리서치 근거

- [Michelin Guide](https://guide.michelin.com/us/en), [Field Notes(Draplin Design Co.)](https://en.wikipedia.org/wiki/Field_Notes):
  현장 기록·도장 미학. 절제된 여백과 타이포그래피가 콘텐츠를 신뢰하게 만드는
  방식.
- [Ledger Notes 템플릿](https://webflow.com/templates/html/ledger-notes-website-template)류의
  에디토리얼 사이트: 카드 대신 여백·타이포그래피·괘선으로 구조를 만든다
  ("This approach avoids card-based layouts in favor of intentional whitespace
  and precise typography").
- ["Fill in the Blanks" UI 패턴](https://ui-patterns.com/patterns/FillInTheBlanks):
  입력 필드를 별도 박스가 아니라 문장 속 빈칸으로 배치하는 정석 패턴 — 검색창을
  독립된 패널이 아니라 헤드라인 문장에 통합하는 근거.

## 3. 핵심 개념

이 제품이 실제로 하는 일: 흩어진 블로거들의 독립적인 증언(반복 언급)을 모아
카카오맵으로 대조·검증한다. **별점(임의적 평가)이 아니라 "몇 명이 같은 곳을
짚었는가"가 신뢰의 근거**다.

이를 시각적으로 "한 장의 제보 대장(장부)"라는 단일 컴포지션으로 표현한다.
박스를 쌓지 않고, 마닐라지 배경 한 장이 페이지 처음부터 끝까지 이어지며,
섹션은 얇은 괘선으로만 나뉜다.

**시그니처 요소 — 언급 도장(stamp)**: 별점 대신, 몇 번 언급됐는지를 잉크
도장처럼 찍은 원형 배지로 표현. 히어로·결과 줄·카테고리 칩에 일관되게 등장하는
유일한 장식적 액센트(다른 곳은 전부 절제).

## 4. 팔레트

| 이름 | 값 | 용도 |
|---|---|---|
| `--paper` | `#F1ECDF` | 배경 전체(마닐라지, 색인카드 톤) |
| `--ink` | `#1F2A24` | 본문 텍스트(짙은 잉크빛, 순검정 아님) |
| `--muted` | `#7C8579` | 보조 텍스트 |
| `--line` | `#D8CFB4` | 괘선(장부 줄) |
| `--stamp` | `#A23B2E` | 언급 도장 잉크색(시그니처, 유일한 강조색) |
| `--kakao` | `#FFCD00` | 카카오맵 링크 — 실제 브랜드색, 장식 아님(서비스 구분 기능) |
| `--naver` | `#03C75A` | 네이버지도/출처 링크 — 실제 브랜드색 |

크림+테라코타(가장 흔한 AI 기본값)를 의도적으로 피해 마닐라지+옥스블러드
조합으로 방향을 틀었다. 카카오/네이버 색은 장식이 아니라 실제 어느 서비스로
연결되는지 구분하는 기능적 선택이다.

## 5. 타이포그래피

- 표제(헤드라인, 브랜드): **Gowun Batang**(세리프) — 따뜻한 기록/에디토리얼 톤.
  Google Fonts, 실제 로딩 확인 완료.
- 본문: **Pretendard** — 기존 유지하되, 실제로는 로딩된 적이 없던 버그(이름만
  참조하고 `@font-face`/CDN 링크가 없었음)를 이번에 같이 고친다(jsDelivr CDN,
  로딩 확인 완료).
- 데이터(도장 숫자, 순위, 전화번호): **IBM Plex Mono** — 타뷸러 느낌, 도장에
  찍힌 숫자처럼. Google Fonts, 로딩 확인 완료.

## 6. 전체 컴포지션 (박스 쌓기 → 한 장의 장부)

기존 구조에서 걷어내는 것: `border-radius`가 큰 흰 카드, `box-shadow`, 장식용
pill 라�스("START PICKING" 류), 아이콘+제목+설명이 동일하게 반복되는
feature-grid 박스.

```
┌─────────────────────────────────────────────────────┐
│ Placepick                                    (얇은 헤더줄, 로고만) │
├─────────────────────────────────────────────────────┤ ← 헤어라인 1개
│                                                       │
│   블로그 100개 중                                     │
│   ＿＿＿＿＿＿＿＿＿ 어디가 좋을까    [화살표/도장]      │ ← 헤드라인=검색창
│   (밑줄 안에 실제 input, 별도 박스 없음)                │
│                                                       │
│              ⟨스탬프 큰 그래픽, 기울어진 도장⟩          │ ← 시그니처, 여백 위 단독
│                                                       │
├─────────────────────────────────────────────────────┤ ← 헤어라인
│ 01  버티샌드위치하우스 성수점              ⟨●33⟩      │
│     서울 성동구 · 카페 · 영업중 11-22                  │
├─────────────────────────────────────────────────────┤ ← 줄마다 괘선(카드 아님)
│ 02  성수다락                               ⟨●13⟩      │
│     ...                                               │
├─────────────────────────────────────────────────────┤
│              증언 4개 보기 ▸  [카카오맵] [네이버]       │
├─────────────────────────────────────────────────────┤
│ 수집 ── 추출 ── 매칭        (가로 프로세스 라인, 박스 X) │
├─────────────────────────────────────────────────────┤
│ Placepick · 흩어진 취향을 한곳에 모으는 가장 쉬운 방법  │
└─────────────────────────────────────────────────────┘
```

- **검색**: 별도 패널 없이 헤드라인 문장 속 빈칸에 직접 입력(fill-in-the-blank
  패턴). 버튼은 밑줄 끝 화살표/도장 아이콘.
- **결과 목록**: 카드+그림자 대신 장부처럼 괘선으로만 구분된 연속 목록. 도장은
  각 줄 오른쪽 인라인.
- **로딩 상태**: 박스 없이 페이지 흐름 안의 상태 한 줄(타자기 커서 느낌).
- **작동 방식**: 박스 3개 대신 가로로 이어지는 라인 위에 3단계 나열(실제 순차
  과정이므로 번호는 유지, 박스는 제거).
- **지역 개요(overview) 카드**: 동일하게 괘선 구분 목록 + 카테고리는 도장이
  아닌 얇은 밑줄 탭 형태로.

## 7. 자체 검토

- 크림/세리프/테라코타, 다크+네온 단색 강조, 신문 그리드 3가지 흔한 AI 기본값
  중 어느 것도 그대로 채택하지 않았다 — 마닐라지+옥스블러드는 "증언을 모으는
  실무 기록"이라는 제품 본질에서 나온 선택이다.
- 별점 대신 도장: 이 제품이 실제로 세는 값(언급 횟수)을 그대로 시각화한 것이라
  임의적이지 않다.
- 카드+그림자를 걷어내고 괘선 기반 장부 구조로 바꾼 것은 "AI가 만든 티가 난다"는
  구체적 피드백에 대한 직접적 대응이다.
- 절제: 장식은 도장 하나로 한정하고, 나머지(타이포그래피·여백·괘선)는 조용하게
  유지한다.

## 8. 적용 범위

`frontend/src/app.css` 전면 재작성, `frontend/src/App.svelte`의 마크업 구조
조정(패널 wrapper 제거, 검색 인풋을 헤드라인에 통합, 결과 목록을 카드에서
괘선 목록으로), `frontend/index.html`에 폰트 `<link>` 추가. 기존 기능(로딩
메시지, 검증된 카피, API 연동)은 그대로 유지 — 시각적 재구성만 진행한다.
